4. ETL & PROCESSAMENTO (PIPELINE CORE)
   ├─ backend/app/etl/__init__.py
   │  ├─ TransactionIngestor
   │  ├─ TransactionClassifier
   │  └─ run_shadow_invoice_detection()
   │
   ├─ backend/app/etl/transaction_ingestor.py (200+ linhas)
   │  ├─ Classe: TransactionIngestor
   │  ├─ process(transactions) → clean_df, metrics
   │  └─ Limpeza: duplicatas, nulls, tipos de dados, normalização
   │
   ├─ backend/app/etl/transaction_classifier.py (300+ linhas)
   │  ├─ Classe: TransactionClassifier
   │  ├─ predict(clean_df) → categorized_df com 'predicted_category'
   │  └─ ML: Decision Tree / Logistic Regression (treinado)
   │
   ├─ backend/app/etl/income_profiler.py (200+ linhas) ⭐ MI.6
   │  ├─ Classe: IncomeProfiler
   │  ├─ build(transactions_df) → IncomeProfile
   │  ├─ Atributos: monthly_net_income, confidence, source
   │  └─ Detecta renda a partir de transações de crédito recorrentes
   │
   ├─ backend/app/etl/spending_anomaly_detector.py (250+ linhas) ⭐ MI.1
   │  ├─ Classe: SpendingAnomalyDetector
   │  ├─ detect(recent_df, history_df, income_profile) → List[Anomaly]
   │  ├─ Tipos: UNUSUAL_AMOUNT, UNUSUAL_FREQUENCY, UNUSUAL_MERCHANT
   │  └─ Machine learning: Isolation Forest / Statistical methods
   │
   ├─ backend/app/etl/shadow_invoice_detector.py (300+ linhas)
   │  ├─ Classe: ShadowInvoiceDetector
   │  ├─ detect(transactions_df) → shadow_invoices
   │  ├─ Padrões: "01/10", "1/10" (parcelamentos), "Netflix" (assinaturas)
   │  └─ Retorna lista de projeções futuras + confidence score
   │
   └─ backend/app/etl/cashflow_projector.py
      ├─ Classe: CashflowProjector
      ├─ project(transactions, income, shadow_invoices, horizon_days)
      └─ Retorna DataFrame com projected_balance por dia

🔗 FLUXO DE CHAMADAS PRINCIPAIS

1. Login & Auth
   └─ POST /auth/token
      ├─ Valida email/senha
      ├─ Gera JWT token
      ├─ Retorna {access_token, token_type, user_id}
      └─ Frontend salva em st.session_state["jwt_token"]

2. Dashboard Inicial
   ├─ GET /forecast/{user_id}              (Projeção 30d)
   ├─ GET /safe-to-spend/{user_id}         (Orçamento)
   ├─ GET /alerts/{user_id}                (Avisos)
   └─ GET /shadow_invoice/{user_id}        (Obrigações)

3. ETL de Dados (Background/Webhook)
   ├─ POST /transactions/webhook           (Pluggy)
   ├─ ETL Ingestor (limpeza)
   ├─ ETL Classifier (categorização)
   └─ Salva em Postgres

4. Agent IA Conversation
   ├─ POST /chat/
   ├─ LLM + Estado anterior
   ├─ Decide qual ferramenta usar
   ├─ Chama ferramenta (GET forecast, etc)
   └─ Retorna resposta em linguagem natural
